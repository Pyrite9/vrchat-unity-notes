# Unity Field Notes

Rules for making VRChat avatars in Unity: Render Queue, bounds, color drift, and pitfalls that catch experienced creators. Each rule says what goes wrong if you skip it and what to do instead.

| Language | Page |
|---|---|
| 한국어 | https://pyrite9.github.io/vrchat-unity-notes/ |
| 日本語 | https://pyrite9.github.io/vrchat-unity-notes/ja/ |
| English | https://pyrite9.github.io/vrchat-unity-notes/en/ |

- **한국어** — VRChat 아바타를 Unity로 만들면서 정리한 규칙입니다. 항목마다 지키지 않으면 무슨 일이 생기는지, 어떻게 하면 되는지를 적었습니다.
- **日本語** — VRChat アバターを Unity で作りながらまとめたルールです。項目ごとに、守らないと何が起きるか、どうすればよいかを書きました。

Checked with Unity 2022.3.22f1, VRChat SDK 3.10.x, lilToon 2.x, Modular Avatar, Avatar Optimizer, NDMF.

Found a mistake? Please open an Issue.
